# The Closet WhatsApp Revenue Demo

A premium Next.js sales demo showing how a fashion business can turn Instagram, Google, website and WhatsApp traffic into qualified customer conversations, product discovery, human handoffs and follow-ups.

## Demo flow

Traffic source → WhatsApp-style concierge → intent/category discovery → lead status → follow-up.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Scope

This is a sales demo, not an official The Closet product. Product data and automation states are illustrative. The next implementation phase can add real product data, WhatsApp Cloud API, Supabase lead storage, checkout handoff and automated follow-ups.
